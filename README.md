# Waitlist fill-rate calculator

Free single-file calculator for salons, clinics and studios: how many
cancelled slots your waitlist can actually refill each month, the fill
rate you reach, and what stays empty.

- Open `index.html` in any browser, or use the hosted copy:
  https://vlotstroom.github.io/waitlist-calculator/
- English + Nederlands, no signup, no external requests, nothing sent.

Honest math, no benchmarks claimed:

- Open slots per month = appointments x (cancellations + no-shows %) x 4.33
- Fillable from waitlist = waitlist members x reply rate
- Refilled = min(open slots, fillable); each member counts once per month
